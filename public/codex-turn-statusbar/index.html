Codex Turn Status Bar

一个安静的 Codex 菜单栏状态灯

不抢焦点、不发声音。Codex 有未处理轮次时，macOS 菜单栏图标会变绿；空闲时回到白色圆环。

复制以下命令到终端运行，即可下载 DMG 并安装到 Applications。

curl -fsSL http://10.1.111.12:18000/codex-turn-statusbar/install.sh | sh
下载 macOS DMG

把下面这一句话发给另一个 Agent。它只需要读取 `install.md`，就能完成下载、校验和安装。

Agent 安装提示词

帮我安装 Codex Turn Status Bar：http://10.1.111.12:18000/codex-turn-statusbar/install.md

安装后打开 App，并重启 Codex Desktop 或新开会话，让 Codex 重新加载 notify 配置。

一眼看懂当前状态

图标只保留两个重要信号：没有未处理内容时保持安静，有未读或待处理轮次时变成醒目的绿色消息。

空闲 白色圆环停在菜单栏里，不抢注意力。
有未处理内容 绿色消息图标出现，提示可以回到 Codex 处理。
绿色提醒 有未处理或未读 Codex 活动时，状态栏图标变绿。
不打扰 不播放声音，不自动激活 Codex，不打断当前窗口。
自动配置 App 启动时同步 `codex-turn-notify` 并更新 Codex 配置。
